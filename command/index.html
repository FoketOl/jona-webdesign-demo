DNS Belgium

Officieel .be-registry — beschikbaarheid rechtstreeks checken

Prijzen (geel) bij elke klant hierboven zijn indicatieve markttarieven voor een vergelijkbaar pakket bij die host — niet hun bevestigde, echte factuur. Om dat zeker te weten moeten we het rechtstreeks aan de zaak vragen (pas relevant zodra iemand akkoord gaat). *OVH: enkel VPS-tarieven gevonden (€4-20/mnd), geen gedeeld-hosting-prijs bevestigd. Dstny is een telecom-/communicatiebedrijf, geen standaard webhost — hun website loopt vermoedelijk via een gebundelde dienst, geen vergelijkbaar publiek tarief gevonden.
